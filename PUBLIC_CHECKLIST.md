# Public release checklist

- [ ] No real appToken is present
- [ ] No real GAS /exec URL is hard-coded
- [ ] No customer names, phone numbers, addresses, or photos are present
- [ ] No Google Drive or Spreadsheet IDs are hard-coded
- [ ] Default worker names are generic samples
- [ ] Demo URL is intentional
- [ ] Decide whether to add a LICENSE (MIT etc.)
